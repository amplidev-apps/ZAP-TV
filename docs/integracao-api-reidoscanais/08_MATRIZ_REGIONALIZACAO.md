## Observação crítica
A distribuição de EPG **não** acompanha a regionalização: a API Rei dos Canais fornece **um** EPG nacional por rede (Globo, SBT, Record, Band, RedeTV!, TV Cultura, TV Brasil). Portanto, ao regionalizar a reprodução, o EPG exibido para a afiliada será o EPG nacional da rede — comportamento a documentar ao usuário (doc 09, §EPG).
